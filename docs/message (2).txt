الدليل الأقوى: route inventory نفسه

يوجد E2E رسمي باسم Sprint 13F Homework final closeout route inventory. هذا الاختبار يسجل routes المكتملة، ثم يتحقق صراحة أن routes المؤجلة غير مسجلة. routes المكتملة تشمل Homework assignments/questions/attachments، teacher homework dashboard/classes/questions/attachments/submissions/review، student homeworks/submission/answers/attachments/submit، وparent child-scoped read routes.

ونفس الاختبار يثبت أن القائمة التي أرسلتها تقريبًا موجودة كـ absent routes، ومنها:

GET/POST /api/v1/homework/submissions
GET/POST /api/v1/homework/questions
GET/POST /api/v1/homework/attachments
student submission/history/questions/attachments routes
parent submit/submission/questions/attachments routes
GET /api/v1/parent/homeworks
teacher .../sync-grade-item

كما يمنع أي homework/student/teacher route تحتوي proof, upload, xp, أو reward، ويمنع parent homework routes التي تحتوي submit/submission/question/answer/attachment/proof/upload.

ما هو منفذ فعليًا؟
1. Homework Core questions موجود، لكن ليس كـ flat route

غير موجود:

GET /api/v1/homework/questions
POST /api/v1/homework/questions

الموجود فعليًا:

GET /api/v1/homework/assignments/:homeworkId/questions
POST /api/v1/homework/assignments/:homeworkId/questions
GET /api/v1/homework/assignments/:homeworkId/questions/:questionId
PATCH /api/v1/homework/assignments/:homeworkId/questions/:questionId
DELETE /api/v1/homework/assignments/:homeworkId/questions/:questionId

وهذا واضح من HomeworkQuestionsController لأنه مربوط بـ:

@Controller('homework/assignments/:homeworkId/questions')
2. Homework Core attachments موجود، لكن ليس كـ flat route

غير موجود:

GET /api/v1/homework/attachments
POST /api/v1/homework/attachments

الموجود فعليًا:

GET /api/v1/homework/assignments/:homeworkId/attachments
POST /api/v1/homework/assignments/:homeworkId/attachments
PATCH /api/v1/homework/assignments/:homeworkId/attachments/:attachmentId
DELETE /api/v1/homework/assignments/:homeworkId/attachments/:attachmentId

والـ controller مربوط بـ:

@Controller('homework/assignments/:homeworkId/attachments')
3. Core submission list/review غير موجود كـ route عام

غير موجود:

GET /api/v1/homework/submissions
POST /api/v1/homework/submissions
GET /api/v1/homework/assignments/:homeworkId/submissions
POST /api/v1/homework/assignments/:homeworkId/submissions/:submissionId/review

لكن يوجد content-level review/read تحت submission محدد:

GET /api/v1/homework/assignments/:homeworkId/submissions/:submissionId/answers
GET /api/v1/homework/assignments/:homeworkId/submissions/:submissionId/answers/:answerId
PATCH /api/v1/homework/assignments/:homeworkId/submissions/:submissionId/answers/:answerId/review
PUT /api/v1/homework/assignments/:homeworkId/submissions/:submissionId/answers/review
GET /api/v1/homework/assignments/:homeworkId/submissions/:submissionId/attachments

وهذا موجود في HomeworkSubmissionContentController.

Parent Homework status

الموجود فعليًا للـ Parent:

GET /api/v1/parent/children/:studentId/homeworks
GET /api/v1/parent/children/:studentId/homeworks/:homeworkId

وهذا فقط ما يقدمه ParentHomeworksController. لا يوجد Post, ولا submit mutation.

غير الموجود فعلًا:

GET /api/v1/parent/homeworks
POST /api/v1/parent/children/:studentId/homeworks/:homeworkId/submit
POST /api/v1/parent/children/:studentId/homeworks/:homeworkId/submission/submit
GET /api/v1/parent/children/:studentId/homeworks/:homeworkId/questions
GET /api/v1/parent/children/:studentId/homeworks/:homeworkId/attachments

لكن مثل الطالب، Parent detail DTO يحتوي:

questions
attachments
submission

داخل ParentHomeworkDetailDto.

إذن questions/attachments للـ Parent ليست route منفصلة، لكنها موجودة ضمن detail response. أما parent submit فهو فعلًا غير منفذ، وهذا متسق مع قرار أن Parent Homework read-only.

POST /api/v1/teacher/homeworks/classes/:classId/assignments/:homeworkId/submissions/:submissionId/grade-sync
